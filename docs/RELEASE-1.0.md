# DailyAPP 1.0 — uso pessoal

Tarefas, agenda, receitas, despesas e orçamento mensal em português, com dados locais, backups e funcionamento offline.

## Arquivos

- `DailyAPP-1.0-pessoal.apk`: instalador Android, para Android 7 ou superior. Usa build Release e o certificado de desenvolvimento da instalação pessoal anterior. Abra no celular para instalar.
- `DailyAPP-1.0-sem-assinatura.ipa`: pacote iPhone, adicionado quando a compilação macOS termina com sucesso. Requer iOS 15.4 ou superior e assinatura pessoal antes de instalar. O IPA não instala sozinho ao ser aberto.
- Arquivos `.sha256`: hashes para conferir a integridade dos downloads.

No Windows, uma opção de assinatura pessoal do IPA é o AltServer/AltStore, obtido de [altstore.io](https://altstore.io). Siga o guia oficial. Contas Apple gratuitas normalmente exigem renovação da assinatura após sete dias. No Linux, essa opção exige acesso a um Windows ou Mac compatível com AltServer.

Se já usa o Android desta sessão, exporte um backup e instale o novo APK sem desinstalar. Mudar a assinatura, limpar dados ou desinstalar pode exigir restaurar um backup.

Os 38 testes da interface passaram e a compilação Android foi verificada. Plugins nativos foram simulados nos testes do navegador; confirme teclado, seletor de arquivos, compartilhamento e persistência no seu aparelho. Esta release não publica o aplicativo nas lojas e não inclui sincronização automática ou conexão com bancos.

Consulte o [guia de instalação](https://github.com/NyxPjct/DailyAPP/blob/main/docs/CELULAR.md).
